When you reopen a running game, the page now reads the turn and move number
from the game that accepts the players’ moves. If a move is played while the
server is loading the page, a delayed database read can no longer restore an
older turn. In Wild 16, the shared move number advances when a player
completes a move, including when a private retry preceded it.
